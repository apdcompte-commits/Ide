=================================================================

--------------------------------
index.html          Page d'accueil (bilingue FR/EN)
inscription.html    Page du formulaire d'inscription (bilingue FR/EN)
dossier.php         Page de consultation des dossiers (/dossier)

IMAGES DE LA PAGE D'ACCUEIL
---------------------------
Placez vos images dans assets/img/ :

  assets/img/accueil-1.jpg
  assets/img/accueil-2.jpg
  assets/img/accueil-3.jpg

Si absentes, des images par défaut (Pexels) s'affichent.


LOGO / FAVICON
--------------
  assets/img/logo.png  (remplacez par votre logo, PNG carré 256×256)


TYPES DE FICHIERS ACCEPTÉS
---------------------------
Chaque champ (photo, CV, lettre de motivation, pièce d'identité)
accepte : JPG, JPEG, PNG, DOC, DOCX, PDF.
Tout autre type est refusé avec un message listant les formats autorisés.
Aucune limite de taille.


FONCTIONNEMENT DE L'INSCRIPTION
--------------------------------
1. Le candidat remplit le formulaire et joint ses fichiers.
2. Au clic sur le bouton, le dossier est archivé sur le serveur.
   Un ID unique est généré (ex : DUPONT-Jean-34-a3f8c2).
3. La messagerie du candidat s'ouvre automatiquement avec :
   - Destinataire : invest-initiative@africamail.com
   - Objet : Mon inscription
   - Corps : Je vous transmets mes fichiers de participation à
     l'offre. ID : DUPONT-Jean-34-a3f8c2
     Pour télécharger les fichiers, rendez-vous sur :
     https://votre-site.com/dossier?id=DUPONT-Jean-34-a3f8c2


CONSULTATION DES DOSSIERS
--------------------------
Accédez à :  https://votre-site.com/dossier

1. La page affiche « Veuillez insérer l'identifiant du dossier
   que vous avez reçu par e-mail ».
2. Collez l'ID (ex : DUPONT-Jean-34-a3f8c2) et validez.
3. La page affiche les informations du candidat et les fichiers
   avec un bouton Télécharger pour chacun.
4. Après consultation, utilisez le bouton « Supprimer
   définitivement ce dossier » pour libérer l'espace serveur.


FORMAT DE L'IDENTIFIANT UNIQUE
-------------------------------
Format : NOM-Prenoms-Age-Hex6
Exemple : DUPONT-Jean-34-a3f8c2
- Les 10 premiers caractères du nom et du prénom
- L'âge calculé depuis la date de naissance
- Un suffixe aléatoire de 6 caractères garantissant l'unicité


SÉCURITÉ
--------
- Le dossier data/ est interdit d'accès web (.htaccess)
- Les fichiers sensibles (config.php, .htaccess) sont protégés
- Validation stricte des types de fichiers côté serveur (MIME)
- Protection contre le listage des dossiers (Options -Indexes)
- En-têtes de sécurité HTTP (X-Content-Type-Options, etc.)


DÉPLOIEMENT SUR INFINITYFREE
-----------------------------
1. Créez un compte sur https://www.infinityfree.com
2. Créez un hébergement (sous-domaine gratuit)
3. Dans le File Manager, entrez dans htdocs/
4. Supprimez les fichiers d'exemple
5. Téléversez tout le contenu de girh-site/ dans htdocs/
6. Le site est en ligne : https://votre-site.com
   La consultation des dossiers : https://votre-site.com/dossier
